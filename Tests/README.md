# 本地视频素材

本目录保留已有的 Source 原片和 Generated 导出产物，两个目录均被 Git 忽略。
旧首帧测试场景、宿主测试素材副本、读取器检查程序及测试素材生成脚本已移除。
需要转码时使用组件 Tools~/encodeTool/VideoTool.exe，自行选择输入和输出目录。

Source/Sintel/Sintel.2010.1080p.mkv 为已有原片。
Sintel：Blender Foundation / Durian Open Movie Project，2010，CC BY 3.0。
来源：https://durian.blender.org/download/

本文路径以当前 Tests 目录为基准；Tools~ 路径以 Packages/com.pulse.videoplayer 为基准。
